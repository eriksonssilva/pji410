Os quatro perfis de acessibilidade eleitoral

Um município pequeno sem nenhuma seção acessível e uma cidade grande com metade das seções acessíveis aparecem perto um do outro num ranking pelo percentual de seções acessíveis, mas precisam de ações diferentes. Para separar esses casos, o projeto usa o k-means, um algoritmo de aprendizado de máquina não supervisionado. Ele junta municípios com indicadores parecidos sem receber uma lista de grupos pronta.

Como os grupos foram formados

  1. Indicadores. Para cada município, o projeto calculou quatro números. O primeiro é o percentual de seções que constam como acessíveis. O segundo é o percentual de locais de votação sem nenhuma seção acessível. O terceiro é o número de eleitores com deficiência cadastrados a cada mil eleitores. O quarto é o porte, medido pelo número de eleitores. O percentual de eleitores com deficiência em seções sem acessibilidade ficou fora do modelo porque quase repete o primeiro indicador (correlação de -0,95). Ele aparece só na descrição dos grupos.
  2. Padronização. Alguns municípios têm milhares de vezes mais eleitores que outros. Por isso, o porte e a proporção de eleitores com deficiência entram no modelo em escala logarítmica. Depois, cada indicador é convertido para média 0 e desvio-padrão 1, para que nenhum pese mais só por usar uma escala maior.
  3. Número de grupos. O modelo rodou com 2 a 8 grupos. Para cada caso, o projeto mediu a inércia, usada no método do cotovelo, e o coeficiente de silhueta, que vai de -1 a 1 e cresce quando os grupos ficam mais separados.
  4. Nomes dos grupos. Cada grupo recebeu um nome a partir das medianas dos seus indicadores.
